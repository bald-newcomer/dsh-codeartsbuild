## 4. 更新流程（决策后执行）

1. **人工决策**：§3 表格填 ✅/❌（建议默认采纳：纳入 20016/20020/20019，其余不纳入）
2. **更新 generate-templates.py**：`COMMON` 列表加选中的 template_id（uuid + template_id + name）
3. **跑脚本**：`python docs/example/generate-templates.py` → 更新 step-templates.json + config-template.json
4. **补 core_tool**：手动为新模板加 `core_tool` 字段（20016→python，20020→msbuild，20019→npm）
5. **补组合场景**：combination-scenarios.json 加新场景（如 Python/setuptools、C#/MSBuild、JavaScript/Yarn）
6. **全测**：tsc + vitest run（list-templates.test.ts 的 step_templates 数量断言需同步 14→17）
