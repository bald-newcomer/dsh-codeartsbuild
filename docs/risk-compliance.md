## 1. 安全设计

| 项 | 设计 | 状态 |
|----|------|------|
| 凭据存储 | AK/SK 完全由 KooCLI 管理（`hcloud configure`），插件不接触 | ✅ |
| 敏感字段 | 工具结果序列化剔除 Token/AK/SK；不打印 hcloud 输出中的凭据 | ✅ |
| 注入防护 | 工具参数作为 hcloud 命令参数传递，经转义处理，不做 shell 拼接 | ✅ |
| 日志脱敏 | log-cleaner 输出脱敏（AK/SK/Token/密码/`docker login -u -p`） | ✅ |
| 删除保护 | `delete_job` 描述明示不可逆，调用前须用户确认 | ✅ |
| 大日志管控 | `get_log` 仅 error 分析时获取，按需截断 | ✅ |

## 2. 风险识别与缓解

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| **凭据泄露**（AK/SK/Token 出现在日志或结果） | 高 | KooCLI 托管 + 输出脱敏 + 日志不打印鉴权头 |
| **误删构建任务** | 高 | `delete_job` 用户确认 + 工具描述标注不可逆 |
| **越权操作**（子账号权限过宽） | 中 | 建议最小权限子账号；IAM 按需授权 |
| **构建资源消耗**（重复构建/长轮询） | 中 | 修复闭环 ≤3 轮；wait_build 超时；日志按需 |
| **参数注入**（构建命令注入） | 中 | 参数转义、不做 shell 拼接（repo_build 使用 spawn 数组参数） |
| **产物泄露**（签名 URL 扩散） | 中 | download_url 短时效；不在文档记录全文 |
| **供应链**（依赖被篡改） | 低 | 依赖锁定（lock 文件）；KooCLI 官方源安装 |
| **会话数据残留**（projectId 会话缓存） | 低 | 会话内存不落盘；会话结束即释放 |

## 3. 权限最小化

### 3.1 推荐的 IAM 权限

| 权限 | 说明 |
|------|------|
| CodeArtsBuild 操作权限 | 构建任务管理、执行、查询 |
| CodeArts Repo 只读 | 拉取代码（若构建需读取仓库） |
| 制品仓库读写 | 产物上传/下载 |

> 使用**子账号**并仅授予所需权限，避免主账号 AK/SK。

### 3.2 KooCLI 配置保护

- `~/.hcloud/` 含 AK/SK 与 Token，建议仅当前用户可读写
- 定期轮换 AK/SK，轮换后重新 `hcloud configure set`

## 4. 审计与可观测

| 项 | 规约 |
|----|------|
| 过程留档 | `repo_build` 每次构建自动留档 `.codeartsbuild/build-records/`（输入/命令/产物/问题/交互） |
| 工具调用可追溯 | dsh 会话轨迹记录工具调用序列 |
| 敏感操作留痕 | `delete_job` / 产物下载等敏感操作在留档中记录 |
| 错误可观测 | 统一错误码（E_CONFIG/E_AUTH/E_PARAM/E_API/E_NETWORK/E_TIMEOUT/E_LOG） |

---

## 5. 合规约束

| 约束 | 说明 |
|------|------|
| 数据不出境 | 构建数据留在用户指定 region（如 cn-north-4） |
| 凭据合规 | 插件不存储、不传输 AK/SK/Token 到第三方 |
| 日志合规 | 清洗日志不含凭据与敏感业务信息（镜像名/IP 脱敏） |
| 开源合规 | 依赖遵循 license（MIT）；`docs/example/` 真实日志不入库（含业务痕迹） |
| 操作授权 | 删除/下载等破坏性或外发操作须用户确认 |
